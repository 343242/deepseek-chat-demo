# Database Guidelines

> ORM patterns, queries, and schema management for this project.

---

## Overview

- **ORM**: MyBatis-Plus 3.5.16，全量替换了 JPA
- **数据库**: PostgreSQL 18
- **缓存**: Redis 8.2（Token 存储、权限缓存、IP 限流）
- **本地缓存**: Caffeine（SystemPrompt、ModelParams、验证码）
- **Schema 管理**: Flyway（`src/main/resources/db/migration/`），版本化 SQL 迁移

---

## Schema Management

- **使用 Flyway** 管理数据库迁移，迁移脚本位于 `src/main/resources/db/migration/`
- 命名规范：`V{序号}__{描述}.sql`，如 `V1__init_schema.sql`、`V4__pg_jieba_chinese_fts.sql`
- 迁移脚本必须幂等：使用 `IF NOT EXISTS`、`CREATE OR REPLACE`、`NOT EXISTS` 等保证可重复执行
- 回填大数据量时使用分页 `UPDATE ... LIMIT N` 避免锁表
- `sql/schema.sql` 保留为完整 Schema 参考文档，但不作为主要迁移手段
- 新增表/列/索引一律通过 Flyway 迁移脚本，不直接编辑 `schema.sql`
- Flyway 在 Spring AI PgVectorStore 初始化之前执行，迁移脚本需自行确保基础表存在

### 命名约定

| 类型 | 前缀 | 示例 |
|------|------|------|
| 系统表 | `sys_` | `sys_user`, `sys_role` |
| 业务表 | 无前缀 | `token_usage`, `model_params` |
| 第三方框架表 | 框架原名 | `spring_ai_chat_memory` |
| 唯一索引 | `uk_` | `uk_user_username` |
| 普通索引 | `idx_` | `idx_user_status` |

### 列定义约定

| 规则 | 说明 |
|------|------|
| 主键 | `BIGINT GENERATED BY DEFAULT AS IDENTITY` |
| 时间列 | `TIMESTAMPTZ`（带时区），不用 `TIMESTAMP` |
| 软删除 | `deleted SMALLINT NOT NULL DEFAULT 0`，用 `@TableLogic` |
| 唯一约束 | 使用 partial unique index: `WHERE deleted = 0` |
| 状态字段 | `SMALLINT`，配合枚举类验证 |
| 默认值 | 在 DDL 中定义 `DEFAULT`，不依赖应用层 |

## MyBatis-Plus 使用

### Entity

```java
@TableName("sys_user")
public class SysUser {
    @TableId(type = IdType.INPUT)  // 雪花 ID 手动填入
    private Long id;
    
    @TableLogic
    private Integer deleted;
}
```

### Mapper

继承 `BaseMapper<T>`，复杂查询用 `LambdaQueryWrapper`：

```java
SysUser user = sysUserMapper.selectOne(
    new LambdaQueryWrapper<SysUser>()
        .eq(SysUser::getUsername, username)
        .eq(SysUser::getDeleted, 0)
);
```

### 禁止事项

- ❌ 不使用 `@Transactional` 注解
- ❌ 不使用 JPA / Hibernate
- ❌ 不使用 `selectList` 不加条件（全表扫描）

### 事务

统一使用 `TransactionTemplate` 编程式事务：

```java
transactionTemplate.executeWithoutResult(status -> {
    // 多步数据库操作
});
```

## Redis 使用

| Key 模式 | TTL | 用途 |
|----------|-----|------|
| `auth:token:access:{userId}:{jti}` | 900s | Access Token 元数据 |
| `auth:token:refresh:{tokenHash}` | 86400s | Refresh Token 映射 |
| `auth:status:{userId}` | 无过期 | 用户状态标记 |
| `auth:perm:{userId}` | 300s | 权限缓存 |
| `auth:login:{ip}` | 300s | IP 登录计数 |
| `chat:memory:{conversationId}` | 可配置（默认不过期） | 会话消息（Sorted Set，score=时间戳） |
