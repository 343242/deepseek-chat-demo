## 优化 1：ModelRegistryRefresher 并行拉取模型

| 项目 | 内容 |
|------|------|
| **类型** | 性能优化（启动） |
| **问题** | 3 个 Provider 串行 HTTP 拉取模型列表，总耗时 = 各 Provider 耗时之和 |
| **发现方式** | 启动日志时间线分析：minimax 445ms + zhipu 42ms + deepseek 230ms = ~700ms |
| **解决方案** | 用 `CompletableFuture` + 虚拟线程并行拉取模型列表，串行创建 ChatClient |
| **效果** | 刷新耗时 ~700ms → ~450ms（取最慢的 Provider） |
| **状态** | ✅ 已完成（commit `64c0194`） |
