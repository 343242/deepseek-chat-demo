## 表详情

### 1. sys_user — 用户表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | `BIGINT` | PK, GENERATED BY DEFAULT AS IDENTITY | 用户 ID（雪花算法生成） |
| `username` | `VARCHAR(50)` | NOT NULL | 用户名，软删除后可复用 |
| `password` | `VARCHAR(100)` | NOT NULL | BCrypt 哈希 |
| `nickname` | `VARCHAR(50)` | | 昵称 |
| `email` | `VARCHAR(100)` | | 邮箱 |
| `phone` | `VARCHAR(20)` | | 手机号 |
| `avatar` | `VARCHAR(255)` | | 头像 URL |
| `status` | `SMALLINT` | NOT NULL, DEFAULT 1 | 状态：1=启用 |
| `created_at` | `TIMESTAMPTZ` | NOT NULL, DEFAULT NOW() | 创建时间 |
| `updated_at` | `TIMESTAMPTZ` | | 更新时间 |
| `deleted` | `SMALLINT` | NOT NULL, DEFAULT 0 | 逻辑删除：0=正常 |

**索引：**
| 名称 | 类型 | 列 | 条件 |
|------|------|-----|------|
| `sys_user_pkey` | UNIQUE | id | |
| `uk_user_username` | UNIQUE | username | WHERE deleted = 0 |
| `uk_user_email` | UNIQUE | email | WHERE deleted = 0 AND email IS NOT NULL |
| `idx_user_status` | btree | status | WHERE deleted = 0 |

**设计要点：**
- 使用 partial unique index 解决软删除下的唯一约束问题
- 邮箱允许 NULL，但非 NULL 时在未删除范围内唯一
- 密码使用 BCrypt（cost=10）哈希存储

### 2. sys_role — 角色表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | `BIGINT` | PK, GENERATED BY DEFAULT AS IDENTITY | 角色 ID |
| `role_name` | `VARCHAR(50)` | NOT NULL | 角色名（如 ADMIN, USER） |
| `role_desc` | `VARCHAR(100)` | | 角色描述 |
| `status` | `SMALLINT` | NOT NULL, DEFAULT 1 | 状态 |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | 创建时间 |
| `updated_at` | `TIMESTAMPTZ` | | 更新时间 |
| `deleted` | `SMALLINT` | NOT NULL, DEFAULT 0 | 逻辑删除 |

**索引：** `uk_role_name` UNIQUE on `role_name` WHERE deleted = 0

### 3. sys_permission — 权限表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | `BIGINT` | PK | 权限 ID |
| `permission_name` | `VARCHAR(50)` | NOT NULL | 权限码（如 `chat:send`） |
| `permission_desc` | `VARCHAR(100)` | | 描述 |
| `resource_type` | `VARCHAR(20)` | NOT NULL | 资源类型（如 API） |
| `resource_key` | `VARCHAR(100)` | | 资源路径 |
| `parent_id` | `BIGINT` | | 父权限 ID（预留树形结构） |
| `status` | `SMALLINT` | NOT NULL, DEFAULT 1 | 状态 |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | |
| `updated_at` | `TIMESTAMPTZ` | | |
| `deleted` | `SMALLINT` | NOT NULL, DEFAULT 0 | |

**索引：** `uk_permission_name` UNIQUE on `permission_name` WHERE deleted = 0

---

### 4. sys_user_role — 用户角色关联表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `user_id` | `BIGINT` | PK, FK → sys_user(id) | 用户 ID |
| `role_id` | `BIGINT` | PK, FK → sys_role(id) | 角色 ID |

**设计：** 联合主键，一个用户可有多个角色。

### 7. model_params — 模型参数表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | `BIGINT` | PK | |
| `model_id` | `VARCHAR(100)` | NOT NULL | 模型 ID |
| `param_key` | `VARCHAR(100)` | NOT NULL | 参数名（如 temperature） |
| `param_value` | `VARCHAR(500)` | NOT NULL | 参数值 |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | |
| `updated_at` | `TIMESTAMPTZ` | | |

### 8. token_usage — Token 用量表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | `BIGINT` | PK | |
| `conversation_id` | `VARCHAR(100)` | | 对话 ID |
| `model_id` | `VARCHAR(100)` | | 模型 ID |
| `prompt_tokens` | `BIGINT` | DEFAULT 0 | 输入 token |
| `completion_tokens` | `BIGINT` | DEFAULT 0 | 输出 token |
| `total_tokens` | `BIGINT` | DEFAULT 0 | 总 token |
| `duration_ms` | `BIGINT` | DEFAULT 0 | 耗时(ms) |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | |

**索引：** `idx_usage_conversation`, `idx_usage_model`, `idx_usage_created`

**设计：** 只追加，不做 UPDATE/DELETE，用于统计分析。

---

### 9. spring_ai_chat_memory — 对话记忆表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | `BIGINT` | PK | |
| `conversation_id` | `VARCHAR(255)` | NOT NULL | 对话 ID |
| `role` | `VARCHAR(50)` | NOT NULL | 角色 (user/assistant/system) |
| `content` | `TEXT` | NOT NULL | 消息内容 |
| `created_at` | `TIMESTAMP` | NOT NULL | 注意：无时区 |

**索引：** `idx_memory_conv_created` on `(conversation_id, created_at DESC)`

**设计：** Spring AI JDBC ChatMemory 的默认表结构，由框架读写。

## Redis 使用

数据库外的补充存储，不属于 PostgreSQL 表：

| Key 模式 | TTL | 用途 |
|----------|-----|------|
| `auth:token:access:{userId}:{jti}` | 900s | Access Token 元数据 + 角色列表 |
| `auth:token:refresh:{tokenHash}` | 86400s | Refresh Token → userId 映射 |
| `auth:status:{userId}` | — | 用户状态标记 (disabled/deleted) |
| `auth:perm:{userId}` | 300s | 用户权限缓存 |
| `auth:login:{ip}` | 300s | IP 登录尝试计数 |

## 潜在问题与改进建议

| # | 问题 | 建议 |
|---|------|------|
| 1 | `spring_ai_chat_memory.created_at` 用 `TIMESTAMP` 无时区，与其他表的 `TIMESTAMPTZ` 不一致 | Spring AI 管控的表，暂不动；长期可考虑自定义 Schema |
| 2 | `token_usage` 无 `user_id` 列，无法按用户统计 | 新增 `user_id BIGINT` 列并加索引 |
| 3 | `sys_permission.parent_id` 预留了树形但未使用 | 如不需要层级权限可移除，简化模型 |
| 4 | `model_params` 用 KV 模式查询时需要聚合 | 如果参数固定（temperature/topP/maxTokens 等），可改为列式存储 |
| 5 | 软删除的关联表（sys_user_role, sys_role_permission）没有清理逻辑 | 删除用户/角色时应清理关联数据 |
