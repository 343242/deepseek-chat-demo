# 05 · 用量统计线框

> **页面类型**：仪表盘（图表 + 聚合表 + 明细，个人维度）
> **路由**：`/app/usage`
> **权限**：`usage:view`（USER / ADMIN；数据始终只含当前用户自己）
> **前置文档**：DESIGN-SYSTEM.md v0.4.0 · INFORMATION-ARCHITECTURE.md v0.3.0
> **状态**：v0.1.0 ASCII 线框（待确认后转 HTML）

> 本页回答一个问题：**我的 token 花在哪了**（哪个模型、哪个会话）。⚠️ 后端只有"按模型 / 按会话"两种聚合与带必选过滤参数的明细，没有按天/月时间桶、没有总计端点、没有费用概念——线框据此设计，不臆造维度（DS 2.7）。

## 2. 页头与时间范围

- 副标题明示范围："仅统计你自己的对话消耗"（后端按当前用户过滤，管理员也无法查他人，见 USAGE-3）
- 时间范围 Select（DS 10.4）：**近 7 天 / 近 30 天（默认）/ 近 90 天 / 自定义**（自定义出 DateRangePicker，`startTime`/`endTime` 传 ISO OffsetDateTime）
- 后端默认 `startTime = now - 30 天`、`endTime` 可空、**无最大窗口限制**；切换范围 → 重新请求两个聚合接口
- 状态写 URL query（`?range=30d` 或 `?from=&to=`），刷新可恢复

## 3. 汇总卡（3 张，客户端汇总）

```
┌────────────────────┐
│ 总请求              │   ← 标签 --font-size-sm --text-tertiary
│ 128                │   ← 数字 --font-size-2xl --font-bold（DS 13.8 千分位/万）
│                    │
└────────────────────┘
```

| 卡片 | 值 | 来源 |
|------|----|------|
| 总请求 | Σ requestCount | 前端对当前维度聚合结果求和 |
| 总 Token | Σ totalTokens，辅行 `↑{Σ prompt} ↓{Σ completion}` | 同上 |
| 平均耗时 | Σ(totalTokens×avgDurationMs)/ΣtotalTokens 加权，或简单 Σ(avg)/N | 同上 |

> ⚠️ 后端无总计端点、聚合接口无合计行，汇总为**前端求和**（USAGE-1）。数字右对齐（DS 5.6/13.8），容器 Card（DS 10.9，radius-lg）。

## 5. 维度 Tabs 与聚合表

Tabs（DS 10.13）：**按模型**（默认）/ **按会话**，对应：

| Tab | 接口 | groupKey |
|-----|------|----------|
| 按模型 | `GET /api/usage/stats/model?startTime=&endTime=` | modelId |
| 按会话 | `GET /api/usage/stats/conversation?startTime=&endTime=` | conversationId |

**聚合表**（Table，DS 10.10；数字列右对齐）：

| 列（按模型） | 来源 UsageStats | 格式 |
|------|------|------|
| 模型 | groupKey | mono 字体 |
| 请求次数 | requestCount | 千分位 |
| ↑ 输入 Token | totalPromptTokens | 万缩写（DS 13.8） |
| ↓ 输出 Token | totalCompletionTokens | 同上 |
| 总 Token | totalTokens | 同上 |
| 平均耗时 | avgDurationMs | DS 13.8（650ms / 1.5s / 2m 15s） |

- ⚠️ 聚合结果后端**无显式 ORDER BY**，前端按 totalTokens 降序排序后再渲染（USAGE-2）
- 按会话 Tab 增加首列"会话"：`groupKey` 去掉 `u_{userId}_` 前缀（复用 `lib/conversation-id.ts` 的 `toRawConversationId`），渲染为链接 → `/app/chat/:rawId`

## 6. 明细表（点击聚合行触发）

明细接口 `GET /api/usage/records` 的 `model` / `conversation` **二选一必填**（两者都缺后端报 103002"请指定 model 或 conversation 参数"）——因此明细**不是全量流水**，而是"选中某个模型/会话后的下钻"：

- 聚合表行点击 → 行高亮（`--bg-selected`），下方明细区标题变为"明细 · {modelId 或 会话}"，请求 `?model={groupKey}` 或 `?conversation={groupKey}`
- 明细列：createdAt（DS 13.3 完整格式）、modelId（mono）、↑ promptTokens、↓ completionTokens、totalTokens、durationMs
- ⚠️ 明细**无分页、全量 List**（按 createdAt 倒序）——前端只渲染最近 200 条 + 底部提示"仅显示最近 200 条记录"（USAGE-2）
- 未选中聚合行时明细区显示占位说明："点击上方任意一行查看调用明细"

## 7. 状态全集

| 状态 | 表现 |
|------|------|
| 加载 | 汇总卡 + 图表 + 表格各自骨架（DS 9.5），不整页 Spinner |
| 空状态（新用户） | "暂无用量数据 / 开始对话后这里会显示 Token 用量"（DS 13.6），无行动按钮 |
| 空状态（所选时间范围无数据） | "所选时间范围内暂无用量" + "查看近 30 天"按钮 |
| 错误 | 内联错误条 + 重试（DS 10.0），不阻断其他卡片 |
| 103002 参数缺失 | 不会发生（明细必经聚合行点击），防御性处理为 Toast |
