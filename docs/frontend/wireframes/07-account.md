# 07 · 我的账号线框

> **页面类型**：表单页（资料 / 密码 / 偏好三个分区）
> **路由**：`/app/account`
> **权限**：`isAuthenticated()`
> **前置文档**：DESIGN-SYSTEM.md v0.4.0 · INFORMATION-ARCHITECTURE.md v0.3.0
> **状态**：v0.1.1 ASCII 线框（待确认后转 HTML）

> 本页是唯一的自助中心：改资料、改密码、调个人偏好。⚠️ 两个契约事实决定形态：① `GET /api/auth/me` **不返回** createdAt/lastLoginAt（不画注册时间/最近登录）；② 改密成功后后端**吊销全部 token（全端下线）**，必须走"确认后跳登录"的闭环。
>
> **v0.1.1 打磨**：① 外壳补齐（TopBar 内容、主导航后台入口与分隔线、诚实留白标注）；② 头像兜底改昵称首字母（原误用 logo 占位"SR"，DS 10.16）；③ 示例昵称/邮箱弃用泛型名"爱丽丝"。

## 2. 基本资料

**数据源**：`GET /api/auth/me` → `UserInfo { id, username, nickname, email, avatar, roles, permissions }`；提交 `POST /api/auth/me/profile`（**部分更新**：仅提交被改动字段）。

| 字段 | 控件 | 校验（后端 `UserUpdateRequest`） | 备注 |
|------|------|--------------------------------|------|
| 用户名 | 只读文本 | — | 登录名不可改，`--text-tertiary` |
| 昵称 | Input | `@Size(max=50)`，提交时 trim | |
| 邮箱 | Input | `@Email` + `@Size(max=100)`，后端 trim+小写，重复报 `EMAIL_USED` | 错误文案"该邮箱已被使用" |
| 手机号 | Input | `@Pattern(大陆手机号 或 空)` | 帮助文本"用于联系，可选"；空串=清空 |
| 头像地址 | Input + 预览 | `@Size(max=255)` + 须为 `http(s)://` 或 `/` 开头 | ⚠️ **无头像上传端点**，仅支持填 URL（ACC-1）；Avatar 实时预览（有图 cover，无图首字母兜底，DS 10.16） |
| 角色 | 只读 Badge 列表 | — | roles 渲染；permissions 不在本页展示（无管理价值） |

- **保存修改**：脏检测（DS 7.5 离开确认），仅提交 dirty 字段；成功 Toast"资料已保存"，写回 auth-store（全局昵称/头像即时生效）
- 权限：改资料是自助能力，仅 `isAuthenticated()`，无额外权限码

## 3. 修改密码

提交 `POST /api/auth/me/password` `{ oldPassword, newPassword }`——**后端无 confirmPassword 字段，一致性由前端校验**（zod refine"两次密码不一致"）。

| 字段 | 校验 | 错误文案 |
|------|------|---------|
| 当前密码 | `@NotBlank` | "当前密码不能为空"；错误报 `OLD_PASSWORD_ERROR`"当前密码不正确" |
| 新密码 | `@NotBlank` + `@Size(min=8, max=72)`；**服务端强度**：不含任何空白字符 + 大写/小写/数字/特殊字符至少 3 种（`PASSWORD_RULE_ERROR`） | "新密码需 8-72 位" / 原样显示后端强度提示 |
| 确认新密码 | 前端一致校验 | "两次输入的密码不一致" |

**提交闭环（关键交互）**——改密成功 = 全端下线（后端吊销该用户全部 access/refresh token）：

1. 点"修改密码" → ConfirmDialog：**"修改密码? / 修改成功后你将在所有设备退出登录，需要重新登录。/ [继续修改]**（primary；非破坏操作但后果需预告）
2. 成功 → Toast"密码已修改，请重新登录" → 清空前端 auth-store → `navigate('/auth/login')`（**不带 redirect 回跳**——回跳到账号页无意义）
3. 失败（旧密码错/强度不足）→ 表单内联错误，停留在本页

📐 强度规则帮助文本常显于新密码框下方（DS 10.22 help text），不做实时强度条（规则是"至少 3 种"的布尔判定，非分级）。

## 4. 偏好设置（纯本地，无后端）

| 偏好 | 控件 | 存储 | 说明 |
|------|------|------|------|
| 界面主题 | RadioGroup 三选：跟随系统（默认）/ 浅色 / 深色 | `theme-store`（localStorage，已有实现） | 与 TopBar 主题切换钮**同一状态源**，两处联动（DS 14.1） |
| 默认模型 | Select（数据源 `GET /api/models/detail` 仅 CHAT，DS 11.2 分组） | `localStorage: srag.lastModel`（已有 key） | 聊天输入区 ModelSelector 的默认选中值（02 篇 §4.2"上次使用的模型"），两处共享 |

> 偏好是浏览器本地偏好（换设备不同步），帮助文本注明"偏好保存在当前浏览器"。无"默认 RAG 开关/默认模式"项——聊天页已有记忆逻辑（模型记忆），不重复造设置项（克制）。
