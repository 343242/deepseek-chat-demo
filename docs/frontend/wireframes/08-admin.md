# 08 · 后台管理线框（系统提示词 / 用户管理 / 角色权限）

> **页面类型**：AdminShell 管理表格页 ×3（列表 + 行内操作 + 抽屉详情，IA 3.2 单栏 + 抽屉模式）
> **路由**：`/admin/prompts` · `/admin/users` · `/admin/roles`
> **权限**：`prompt:manage` / `user:manage` / `role:manage`（各自独立守卫；侧栏项无权限即隐藏）
> **前置文档**：DESIGN-SYSTEM.md v0.4.0 · INFORMATION-ARCHITECTURE.md v0.3.0

>
> **v0.1.1 打磨**：① 骨架图移除误置于用户管理页的"[+ 新建角色]"主操作（ADM-3：用户管理无新建入口，顶部主操作随页面而异）；② 权限矩阵 `conversation:*` 归"会话"组（原图违反"按前缀分组"自述规则）；③ 删除用户确认文案对齐 13.7 权威表（去"（逻辑删除）"技术细节泄漏）；④ 示例人名弃用 alice/bob 泛型占位。

## 2. 系统提示词（`/admin/prompts`）

### 2.1 概念模型（决定 UI 的三个事实）

1. **一条 = 一个模型**：`system_prompt` 表按 `model_id` UNIQUE，每模型一段全文，无版本/开关/变量占位（`{{var}} 不存在`，promptText 原样发送）
2. **生效优先级**：内置 XML 模板（classpath:static/prompt/*.xml）＞ Redis ＞ **DB（本页可编辑的部分）** ＞ 默认。**凡有内置 XML 的模型（default / deepseek-flash / deepseek-pro 等以 `resources/static/prompt/` 实际文件为准），本页编辑不生效**——被 XML 覆盖（ADM-1）
3. **只作用于 SIMPLE / MULTI_TURN 聊天**；AGENT 模式走独立意图模板（`static/prompt/agent/{intent}.xml`），不经本页

### 2.2 页面布局

```
┌─ 系统提示词 ────────────────────────────────────────────────────────────┐
│ 按模型定制系统提示词（SIMPLE / 多轮模式生效）                              │
│ ┌─ ⚠️ 提示条 ─────────────────────────────────────────────────────────┐ │
│ │ 带有内置模板的模型（如 deepseek 系）优先使用内置模板，此处编辑不生效    │ │
│ └─────────────────────────────────────────────────────────────────────┘ │
│  模型                状态              更新时间                    操作  │
│  deepseek-v4-flash   ⚠️ 内置模板覆盖    —                            ⋮   │
│  glm-5.1             [已自定义]         2026-08-10 14:30           ⋮   │
│  qwen3-max           [默认]             —                          ⋮   │
└──────────────────────────────────────────────────────────────────────────┘
```

**行数据来源**：模型目录（`GET /api/models/detail` 仅 CHAT 能力——提示词只作用于对话）× 参数覆盖表（`GET /api/prompts`，按 modelId 关联）。状态三值：

| 状态 | 判定 | 表现 |
|------|------|------|
| 内置模板覆盖 | modelId 命中内置 XML 名单 | warning Badge + Tooltip"优先级高于此处编辑，修改不生效" |
| 已自定义 | `GET /api/prompts` 含该 modelId | brand Badge，显示 updatedAt |
| 默认 | 无记录且无内置 | neutral Badge |

### 2.3 编辑（Drawer 520px 加宽）

点行/"编辑提示词" → 抽屉，内容 = **SystemPromptEditor**（DS 11.13，v0.4.0 落地）：

```
┌─ 编辑提示词 · glm-5.1 ──────────────────────┐
│ ┌─ 预览区（当前内容，mono 只读滚动）─────────┐│
│ │ <prompt model="glm-5.1">                  ││
│ │   <role>…</role>                          ││
│ │ </prompt>                                 ││
│ └────────────────────────────────────────────┘│
│ [编辑] ← 点击进入编辑态（Textarea + 50000 计数)│
│                                              │
│ 生效规则: 无内置模板的模型，保存后即时生效      │
│                 [取消]  [保存提示词]           │
└──────────────────────────────────────────────┘
```

- 编辑态：mono Textarea（min-height 320px，resize 纵向），右下字数 `当前/50000` 超限变红（DS 10.3）；`@NotBlank` 空内容禁止提交
- 提交 `POST /api/prompts/{modelId}/update { promptText }` → Toast"提示词已保存" → 列表行变 `[已自定义]`
- **删除（恢复默认）**：行菜单 → ConfirmDialog 轻确认"恢复默认提示词? / 将删除该模型的自定义提示词。/ [恢复]" → `POST /api/prompts/{modelId}/delete`

## 3. 用户管理（`/admin/users`）

### 3.1 用户表

```
┌─ 用户管理 ──────────────────────────────────────────────────────────────┐
│ 🔍 搜索用户名/昵称                                共 42 人               │
│  用户名      昵称      邮箱                状态     创建时间        操作 │
│  admin      管理员    admin@example.com   ✅ 启用   2026-06-20      ⋮  │
│  linshuang  林霜      linshuang@…        ✅ 启用   2026-06-21      ⋮  │
│  chenmo     陈默      chenmo@…           ⛔ 禁用   2026-06-25      ⋮  │
│                              < 1 2 3 >                 每页 20 ▾        │
└──────────────────────────────────────────────────────────────────────────┘
```

- 数据：`GET /api/users?page=1&size=20&keyword=`（keyword 匹配 username/nickname，模糊）；页码**从 1 起**
- 字段映射（`UserVO`）：username、nickname、email、status（Badge 4.4.9：1=启用 success / 0=禁用 error）、createdAt（DS 13.3）；phone/avatar 存在于 VO 但列表不展示（详情抽屉显示，密度优先）
- ⚠️ **列表不含 roles**（UserVO 无该字段，ADM-2）——角色只在详情抽屉展示，不画"角色"列
- ⚠️ **无"创建用户"按钮**（仅公开注册）、**无"重置密码"操作**（ADM-3）

### 3.2 详情抽屉（点行打开，480px）

数据：`GET /api/users/{id}` → `UserInfo`（含 roles/permissions）+ 列表行数据合并：

```
┌─ 用户详情 ─────────────────────────────────┐
│ [avatar] 陈默 chenmo                        │
│ 邮箱 chenmo@example.com · 手机 138…            │
│ 状态: [⛔ 禁用]     创建于 2026-06-25        │
│ 角色: [USER]              [分配角色]         │
│ 权限: chat:send · usage:view …（折叠展示）   │
│────────────────────────────────────────────│
│ [编辑资料]  [启用账户]  [删除用户(红,⋮内)]   │
└─────────────────────────────────────────────┘
```

### 3.3 行/抽屉操作

| 操作 | 调用 | 交互 |
|------|------|------|
| 编辑资料 | `POST /api/users/{id}/update` | Modal 表单（nickname/email/phone/avatar，校验同 07 篇 §2 同一 DTO）；仅提交 dirty 字段 |
| 禁用 / 启用 | `POST /api/users/{id}/status?status=0\|1` | **UserStatusToggle**（DS 11.14）。⚠️ **query param 传值，非 JSON body**（ADM-5）。禁用走 ConfirmDialog："禁用账户? / {nickname} 的所有登录将被立即注销，且无法登录。/ [禁用]（destructive）"——后端禁用即吊销其全部 token；启用轻确认即可 |
| 分配角色 | `POST /api/users/{id}/roles { roleIds }` | Modal：角色 Checkbox 列表（数据 `GET /api/roles`），**全量覆盖语义**（提交 = 以勾选集整体替换），帮助文本明示"保存后替换该用户的全部角色"；清空入口 → `/roles/clear` 轻确认。上限 20 个 |
| 删除用户 | `POST /api/users/{id}/delete` | ConfirmDialog："删除用户? / {nickname} 将被删除并立即注销所有登录，此操作不可撤销。/ [删除]（destructive）"（13.7 权威文案，不向用户暴露"逻辑删除"实现细节） |

## 4. 角色权限（`/admin/roles`）

### 4.1 角色表

```
┌─ 角色权限 ──────────────────────────────────────────────────────────────┐
│                                 [新建角色]                                │
│  角色          描述               权限数        更新时间            操作  │
│  ADMIN 🔒     系统管理员          12           2026-06-20          ⋮    │
│  USER 🔒      普通用户            4            2026-06-20          ⋮    │
│  EVALUATOR    评估专员            2            2026-08-01          ⋮    │
└──────────────────────────────────────────────────────────────────────────┘
```

- 数据：`GET /api/roles`（id 升序）；"权限数"来自 `GET /api/roles/{id}`（RoleDetailVO.permissions.length）或详情打开时补齐——列表页仅展示 roleName/roleDesc/updatedAt，权限数列可后置加载
- 🔒 标记：`roleName ∈ {ADMIN, USER}` 为种子内置角色——⚠️ **后端删除无保护**（会级联清绑定并驱逐权限缓存），**前端对内置角色隐藏"删除"与"编辑角色名"**（ADM-4 兜底）

### 4.2 权限配置（抽屉，核心交互）

点行/"配置权限" → 抽屉 = **RolePermissionMatrix**（DS 11.15，v0.4.0 落地）：

```
┌─ 配置权限 · USER ─────────────────────────┐
│ 已选 4 / 12 项           [全选] [清空]     │
│                                           │
│ ▾ 聊天                                     │
│   ☑ 发送聊天消息        chat:send          │
│   ☑ 流式聊天            chat:stream        │
│ ▾ 会话                                     │
│   ☑ 会话管理            conversation:manage│
│ ▾ 用量                                    │
│   ☑ 用量统计查看         usage:view        │
│ ▾ 系统管理（未勾选组）                      │
│   ☐ 系统提示词管理       prompt:manage     │
│   ☐ 用户管理            user:manage       │
│   …                                       │
│───────────────────────────────────────────│
│ 保存将整体替换该角色的全部权限，并对相关     │
│ 用户即时生效（权限缓存已驱逐）              │
│                     [取消]  [保存权限]      │
└───────────────────────────────────────────┘
```

- 数据：全量权限 `GET /api/roles/permissions` → `PermissionVO { id, permissionName(码), permissionDesc(中文名), resourceKey }`；当前角色权限 `GET /api/roles/{id}` → permissions 的 id 集
- **分组**：按 `permissionName` 前缀（`.` 前的域）分组：聊天 / 会话 / 用量 / 模型 / 提示词 / 用户 / 角色 / 评估 / 团队 / 追踪；组标题可折叠；每项显示中文名（permissionDesc）+ 权限码（mono `--text-tertiary`）
- 提交 `POST /api/roles/{id}/permissions/update { permissionIds }`（**全量覆盖**，`@NotEmpty` 至少 1 项、≤50）→ Toast"权限已保存"并刷新角色列表权限数；清空走 `/permissions/clear` 轻确认
- ⚠️ 保存影响即时全局生效（后端驱逐权限缓存）——帮助文本明示，不需额外 ConfirmDialog（保存按钮已是明确意图）

### 4.3 新建 / 编辑角色

| 操作 | 调用 | 表单 |
|------|------|------|
| 新建角色 | `POST /api/roles` | Modal：roleName（`@NotBlank` 2-50，重名报 `ROLE_NAME_EXISTS`"角色名已存在"）+ roleDesc（≤200 选填） |
| 编辑描述 | `POST /api/roles/{id}/update` | ⚠️ 仅 roleDesc 可改（roleName 无修改端点）；内置角色同规则 |
| 删除角色 | `POST /api/roles/{id}/delete` | ConfirmDialog："删除角色? / 将解除该角色与全部用户、权限的绑定，此操作不可撤销。/ [删除]（destructive）"；**内置角色（ADMIN/USER）不显示此项** |

## 5. 状态全集（三页通用）

| 状态 | 表现 |
|------|------|
| 加载 | 表格骨架行（DS 9.5） |
| 搜索无结果 | "未找到匹配项 / 试试调整搜索关键词或筛选条件 / [清除筛选]"（DS 13.6） |
| 空状态 | 提示词："还没有自定义提示词 / 从模型列表选择一个模型开始定制"；角色："还没有角色 / 新建角色以分配权限"；用户列表实际不为空（种子 admin），空态同搜索无结果 |
| 无权限直敲 | 缺对应权限码 → 403 页（IA 2.3） |
| 操作失败 | Toast error，优先显示后端 message（DS 13.5） |
| 并发冲突 | 审批类乐观锁同型场景（如角色被他人删除后再保存）→ 报错后刷新列表 |

## 7. 待确认事项

| 编号 | 事项 | 影响 | 后续动作 |
|------|------|------|---------|
| ADM-1 | **内置 XML 模板优先级高于 DB 提示词** | deepseek 系模型在本页编辑不生效，属易踩坑 | 已用"内置模板覆盖"状态 + 页首提示条明示；建议后端暴露"某模型是否有内置模板"接口（当前前端只能硬编码 XML 名单，`resources/static/prompt/*.xml` 变更时要同步）|
| ADM-2 | **用户列表 UserVO 无 roles** | 列表无角色列，角色只在详情抽屉 | 后端在列表 VO 补 roles（join）后加列；当前不逐行 N+1 拉详情 |
| ADM-3 | **无创建用户 / 重置密码端点** | 管理员无法代建账号、代改密码 | 产品决策：要么保持"用户自助注册+自助改密"，要么后端补端点后 UI 加入口；当前不画 |
| ADM-4 | **角色删除后端无内置保护** | 误删 ADMIN/USER 会破坏权限体系 | 前端按 roleName 屏蔽内置角色删除/改名（兜底）；建议后端加 is_builtin 或删除校验 |
| ADM-5 | **用户状态接口用 query param**（`?status=0`），body 会被忽略 | 传错形态必现 400 | API 层固定 `params` 传值并注释；已在组件规范（DS 11.14）标注 |
