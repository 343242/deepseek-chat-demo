| 检查项 | PRD 合规情况 |
|--------|-------------|
| 权限注解 | ✅ 团队管理 API 标注 `isAuthenticated`、CREATOR、ADMIN 等权限（§6） |

## 二、database-guidelines.md 合规检查

### 2.1 Schema 管理 ✅ 合规

| 规则 | PRD 合规情况 |
|------|-------------|
| 使用 Flyway | ✅ `V7__add_team.sql`（§5.4） |

| 迁移幂等 | ✅ §5.4 明确要求 `IF NOT EXISTS` / `NOT EXISTS` |

### 2.2 列定义约定 ✅ 合规

| 规则 | PRD 合规情况 |
|------|-------------|
| 主键 `BIGINT GENERATED BY DEFAULT AS IDENTITY` | ✅ 三张新表均使用 |
| 时间列 `TIMESTAMPTZ` | ✅ `created_at`/`updated_at`/`joined_at`/`reviewed_at` 均为 TIMESTAMPTZ |
| 软删除 `deleted SMALLINT NOT NULL DEFAULT 0` + `@TableLogic` | ✅ `team` 表使用 |
| 唯一约束 partial index `WHERE deleted = 0` | ✅ `uk_team_name_active` / `uk_team_user_active` |
| 状态字段 `SMALLINT` + 枚举 | ✅ `status`/`role` 均为 SMALLINT + `@EnumValue` 枚举 |
| 默认值在 DDL 中定义 | ✅ `DEFAULT 50`/`DEFAULT 200`/`DEFAULT 1`/`DEFAULT NOW()` |

### 2.3 MyBatis-Plus 使用 ✅ 合规

- Entity 使用 `@TableName` + `@TableId` + `@TableLogic`（§5.1）
- Mapper 继承 `BaseMapper<T>`（§9）
- 查询条件显式包含 `WHERE status = 1`（§5.1 设计说明）
- 无 `@Transactional` 注解，使用 `TransactionTemplate`

### 2.4 ⚠️ 注意项

| 项目 | 说明 |
|------|------|
| `team_member.deleted` 不存在 | ✅ 正确 — 设计说明明确解释不用 `@TableLogic`，改用 `status` 字段 |
| `TRUNCATE vector_store` | ⚠️ Flyway 迁移中执行 TRUNCATE 可行但需注意：如果有其他服务共享该表会受影响。当前单体架构无此问题 |
